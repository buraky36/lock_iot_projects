ONLOI ACCESS CONTROL TERMINAL (OE SERIES) - V2.0.8 OTA PARAMETRELERİ
================================================================================

ÖNEMLİ NOT:
OTA paneline kesinlikle 'full_firmware_OExxxx.bin' yüklenmemelidir! 
Yalnızca 'firmware.bin' dosyası yüklenmelidir.

Bu versiyondaki yenilikler:
1. Wi-Fi Power Save modu kapatıldı (WIFI_PS_NONE - 12V kablolu cihaz her an uyanık).
2. Onloi Cloud Session Keepalive eklendi (CMD_SESSION_START 0x30, 20 saniyede bir gönderilir).
   Böylece terminal boşta beklerken Onloi Cloud cihazı 'Asleep' moduna geçirip komutları (0x5C versiyon sorgusu, kapı açma vb.) QUEUED yapmaz; tüm app istekleri anında cihaza iletilir.
3. Yazılım sürümü V2.0.8 (0x00020008) olarak güncellendi.
4. OSDP PDID sürüm raporlaması 2.0.8 olarak eşitlendi.
